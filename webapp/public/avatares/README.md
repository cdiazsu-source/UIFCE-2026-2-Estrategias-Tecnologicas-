# Fotos de contactos

Coloca aquí las fotos de las personas del directorio de Contactos.

- Formato recomendado: JPG o PNG, cuadrada (se recorta a círculo), ~200×200 px.
- Nombra el archivo con algo estable, p. ej. `sandra-vargas.jpg`.
- En la app, edita el contacto y pon ese nombre de archivo en el campo **Foto**
  (basta el nombre; también acepta una URL completa `https://…`).
- Si el campo Foto está vacío, se muestran las iniciales.

Los archivos de esta carpeta se sirven desde `/avatares/<archivo>`.
